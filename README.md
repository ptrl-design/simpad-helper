# SimPad Helper

SimPad Helper is the small Windows program that sends the MFDs from DCS World
to SimPad on your device, and presses the buttons you tap there.

This repository only holds the downloads. To install, open
[Releases](../../releases/latest), download **SimPad-Helper-Setup.exe** and run
it. Updates then arrive by themselves.

Windows may show "Windows protected your PC" the first time, because the
helper isn't signed yet: click **More info**, then **Run anyway**.
